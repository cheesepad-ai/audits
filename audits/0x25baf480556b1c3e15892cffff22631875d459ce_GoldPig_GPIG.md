
**Impact:**

- Reduced BNB proceeds for marketing/treasury.

**Location:**

**💡 Recommendation:**

#### 🟢 [L-2] Fixed 35,000 gas stipend for BNB transfers may redirect treasury share to marketing

**Description:**
BNB payments to `treasuryWallet` and `marketingWallet` use low-level `.call` with a 35,000 gas stipend. If `treasuryWallet` cannot accept with this gas (e.g., complex fallback), the code redirects that share to `marketingWallet`.

```solidity
uint256 treasuryShare = (bnb * 40) / 100;
uint256 marketingShare = bnb - treasuryShare;

if (treasuryShare > 0) {
    (bool ok,) = treasuryWallet.call{value: treasuryShare, gas: 35000}("");
    if (!ok) marketingShare += treasuryShare; // fallback to marketing
}
if (marketingShare > 0) {
    (bool ok,) = marketingWallet.call{value: marketingShare, gas: 35000}("");
    (ok);
}
```

**Impact:**
- Treasury allocation can be inadvertently diverted to marketing if the treasury receiver reverts or needs more gas. This deviates from the intended 40/60 split.

**Location:**
`_distributeTaxes()` in `GoldPig`.

**💡 Recommendation:**
> **Action Required:** Improve robustness.
> - Increase gas stipend or use `.sendValue` pattern without gas limits.
> - If transfer fails, queue unpaid amounts for manual claim rather than redirecting to marketing.
> - Emit a distinct event when a redirect occurs.
