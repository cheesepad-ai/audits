#### 🟡 [M-1] Incorrect `OwnershipTransferred` Event Emission in `transferOwnership()` and `renounceOwnership()`

**Description:**
The `OwnershipTransferred` event parameters are emitted after updating `_owner`, causing both `previousOwner` and `newOwner` in the event to be identical or zeroed, breaking accurate audit trails.

```solidity
function renounceOwnership() public virtual onlyOwner {
    _owner = address(0);
    emit OwnershipTransferred(_owner, address(0)); // emits (0x0, 0x0) instead of (oldOwner, 0x0)
}

function transferOwnership(address newOwner) public virtual onlyOwner {
    require(newOwner != address(0), "No zero address - call renounceOwnership instead");
    _owner = newOwner;
    emit OwnershipTransferred(_owner, newOwner); // emits (newOwner, newOwner) instead of (oldOwner, newOwner)
}
```

**Impact:**
- Off-chain indexers and users are misled about actual ownership changes.
- Reduces transparency and complicates incident forensics or trust verification.

**Location:**
`Ownable` contract: `transferOwnership()` and `renounceOwnership()`.

**💡 Recommendation:**
> **Action Required:**
> 1. Cache `oldOwner` before assignment and emit with correct parameters:
> 
> ```solidity
> address oldOwner = _owner;
> _owner = address(0);
> emit OwnershipTransferred(oldOwner, address(0));
> ```
> 
> 2. Apply similar fix to `transferOwnership()`.
